BDF → LVGL Glyph

可直接导入原生 BDF 点阵字体。读取 ASCII 32–126、DWIDTH、BBX 与 BITMAP 后转换成 LVGL glyph。默认 1 bpp；2/4/8 bpp 提供更多 Alpha 灰度级供手工编辑，但不会对原始 BDF 自动模糊或重采样。BDF 导出时仅将扩展名改为 .c，不添加后缀。

限制

LVGL C：适用于 lv_font_conv 的未压缩 bitmap_format=0、连续 cmap。BDF：当前读取 ENCODING 32–126；支持目标 1/2/4/8 bpp。1 bpp 为纯二值；更高 BPP 不自动生成灰边，只提供可手工编辑的 Alpha 级别。

拖入或选择 lv_font_conv C 文件，或原生 BDF 点阵字体。
